# Branding — Final Decision

**Chosen brand:** **Yacine Path Hungary**  
**Display lockup:** **Yacine Path** (primary) + **Hungary** (secondary)  
**Tagline:** *From Algeria to Budapest. Step by step.*  
**Social handle (target):** `@yacinepathhungary` or `@yacinepath`  
**Date:** July 2026

---

## Why this name

| Requirement | How Yacine Path Hungary delivers |
|-------------|----------------------------------|
| Keep "Path" (user liked) | **Path** = journey metaphor — orientation → arrival |
| More punch than "Path" alone | **Hungary** adds destination, searchability, university credibility |
| Yacine-first | **Yacine** is the first word students see |
| Algeria → Budapest story | Tagline + eyebrow carry the route; name stays short |

**Rejected alternatives:** Yacine Path alone (too minimal), Yacine Study Hungary (less distinctive), Budapest with Yacine (Yacine not first).
